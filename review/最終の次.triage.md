# 『最終の次』への3モデルの評価 — 仕分け

`review/最終の次` に置かれた Opus-5 / GPT / DeepSeek の評価を、本文と突き合わせて仕分けたもの。
評価は「何が書いてあるか」ではなく「本文の事実と合っているか」「複数のモデルが一致するか」
「直せる種類のものか」で分ける。

## まず、評価そのものの信頼度

| モデル | 引用の正確さ | 読んだ範囲 | 扱い |
| --- | --- | --- | --- |
| Opus-5 | 引用した5箇所すべて本文に一語一句ある | 全文 | **そのまま使える** |
| GPT | 引用はすべて本文にある | 全文 | そのまま使える |
| DeepSeek | 引用は本文にある | **前半のみ**。「三本、見送りました」「香典袋」「始発で行きます」「兄が死にまして」に一切触れず、自分でも「書き出しとしての評価」と書いている | 前半の文体評価としてのみ使う。「男の来歴が不透明」「峰岸の内面が見えない」は後半で解消されている指摘なので**無効** |

3モデルとも点数は 8.5〜9/10 で、ほぼ横並び。**絶対評価の点数は識別力がなく、使えない**。
モデルは褒める方向に偏るので、良し悪しを測るなら別の作品との盲検比較（どちらが良いか）にする。

## 指摘の仕分け

### A. 本文の事実として直せるもの（整合性）

| 指摘 | 本文の確認 | 出典 |
| --- | --- | --- |
| 「夜のあいだは無人になる」と「交代の者が二時に来る」が矛盾 | 39行目と51行目に両方ある。**矛盾は実在** | Opus |
| 「峰岸はそのときは寒さのせいだと思った」の「そのときは」が反転を予告している | 該当文あり。伏線の露出 | Opus |
| 事務室を提案しかけた瞬間に代行の電話が鳴るのが都合よい | 78%の転の直前。構造上は「選択」を成立させる仕掛けだが、偶然に頼っている | Opus |
| 男が三本見送るあいだ軒下にいたのに峰岸が気づかない | 説明が無い。雪と夜で通るが一言あるとよい | Opus |

→ **どれも「直し方」が一意に決まる**。書き直しの指示にそのまま使える。

### B. 複数モデルが一致した作法上の指摘

| 指摘 | 一致 | 本文の確認 |
| --- | --- | --- |
| 告白の核心「四十分あれば行ける町に、十一年行かなかった人間の理由としては、それくらいのものしかありません」を人物が言い切りすぎ | **Opus + GPT** | 90.7%、山の直後。両者とも「半分だけ言わせる」「一割削る」を提案 |
| 説明を減らす方向で磨くべき | Opus + GPT | GPT「あと一割くらい説明を削る」 |

→ 展開ガイド（story_structure.md）に**「露見・告白で核心を人物に言い切らせない」**を加える価値がある。
現在のガイドは転の位置と類型を扱っていて、転の「言わせ方」は扱っていない。

### C. モデル間で割れたもの（好みの領域）

| 指摘 | 立場 |
| --- | --- |
| 比喩が過密 | Opus「前半に続き、作者の手が見える。二、三個削る」／GPT「音の描写が統一されていて良い」／DeepSeek「砂糖の比喩は新鮮で的確」 |
| 「猫の喉のような音」 | Opus「沸騰の音として実感に結びつかない」／GPT・DeepSeek は肯定 |
| 十一年会わなかった理由を明かすか | GPT が両論を書いて「明かさないほうが普遍的」に傾く。Opus は触れず |
| 結びの「外側の一本から順に見えなくなった」 | Opus「ぜひ残して」／GPT「一番作者の手が見える場所」 |

→ 作者が決めること。ただし比喩については測れる事実がある（次項）。

### D. 測って分かったこと

比喩の位置を出すと、5箇所のうち4箇所が本文の**前半40%に集中**している
（7.6% / 29.2% / 37.1% / 38.6% / 86.6%）。密度は 1.39/千字 で分布の中央値付近なのに
Opus が「過密」と感じたのは、**密度ではなく分布**の問題。書き直しループは密度しか見ていないので、
この偏りは検出できない。

→ 文体ガイド（story_craft.md）の比喩の節に「位置の分布」を加え、計測にも「前半／後半の比」を足す余地がある。

## どう使うか

1. **A と B は書き直しの指示にできる**。計測ループが数値を直したのと同じ形式で、
   「矛盾 → 直し方」を並べて渡せば一意に直る
2. **C は渡さない**。モデルの好みを混ぜると、平均的で無難な文章に寄る
3. **D はガイドと計測に反映する**（分布の指標を足す）
4. **点数は捨てる**。比較評価に切り替えるなら、盲検で2本を並べて「どちらが良いか、理由は」を訊く形にする
5. DeepSeek のように途中までしか読まない事故があるので、**評価には本文の末尾の一文を引用させる**
   などして全文を読んだことを確認する
