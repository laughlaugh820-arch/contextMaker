# 書いたときの設計（判定と突き合わせるための、作者側の申告）

評価基準が機能しているかを見るために、**判定を見る前に**書き手の意図を記録したもの。
判定者の答えがこれと一致するか、ずれるならどちらが正しいかで、基準の妥当性を測る。

## 構成（作者の意図）

| 段階 | 位置 | 内容 |
| --- | --- | --- |
| 発端 | 0〜15% | 竜あての手紙だけを運ぶ男。欠落＝返事が来ない仕事。期限＝三月三十一日で路が廃され、残り三通 |
| 承1 | 15.5% | 河原の骨。葉書の老人。**感謝**（畑を焼かれ、結果として救われた） |
| 承2 | 42.7% | 沼。十一年、同じ筆跡の封書。中身は分からない。**執着**（読めない相手に出しつづける） |
| 承3 | 63.8% | 山。子供の手紙。**要求**（返事をください） |
| 転 | 81.9% | 選択。小屋で鉛筆を出し、返事を書く |
| 山 | 88.6% | 露見。同じ文面の紙が、八つの年に自分に届いていた。五十七年持っている |
| 結 | 96.3% | 風景。差入口に落とす。山の明るみ、雪を踏む音 |

- **承の方向**: 感謝 → 執着 → 要求。他人の話が、だんだん自分に向かってくる（外→内）
- **読者と人物の知識差**: 同時。読者も主人公の過去を山まで知らない
- **転の類型**: 選択（書くと決める）。ただし直後の山が露見なので、二つが隣接している

## 意図的に置いたもの

- 老人が「どう思う」と訊き、主人公が「私は運ぶだけです」と答える。主題を人物に言わせない
- 沼の巣に編み込まれた紙片。十一通の行方を主人公は数えない。説明しない
- 「返事が書けるかどうかは、私にはわかりません。届いたということだけは、私が知っています」
  — 竜が答えたとは書かない。届いたことを誰かが知っている、とだけ書く
- 結びで主人公の感情を書かない。雪を踏む音で閉じる

## 意図的に避けたもの

- 竜が生きていた、という逆転
- 主人公が自分の境遇を語る独白
- 感嘆符、三点リーダ。ダッシュも使っていない
