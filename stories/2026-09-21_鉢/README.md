# 展開ガイドの検証 — `--plot 反復`、作家指定なし

```console
$ python3 tools/story.py generate "雪の夜、終電を逃した男が駅員に頼み込む" --plot 反復 --length 3000 --backend cli
```

`context/guide/story_structure.md` を渡して生成した最初の1本。展開の型「反復」を指定し、
作家は指定していない（文体の数値は分布の中央値だけが渡る）。

## 構造の注釈（位置は本文のオフセット）

| 段階 | 位置 | 内容 |
| --- | --- | --- |
| 発端（男が来る） | 3% | 終電を見送った駅員の前に男が現れる |
| 承1 臨時・回送・貨物 | 10% | 他の電車は無いかと順に訊く |
| 承2 除雪車・始発 | 23% | 除雪車に乗せろ、始発は何時か |
| 承3 電話 | 31% | 電話を借りるが誰も出ない |
| 承4 線路を歩く | 38% | 線路を歩かせろ。去年の転落事故で断られる |
| 承5 自転車 | 50% | 自転車を貸せ。断られる |
| 承6 荷物を託す | 57% | 自分は乗れなくていい、荷物だけ運んでくれ |
| 転（日誌で気づく） | 74% | 当直日誌で、先週も先々週も同じ男が同じ電車を見送っていたと気づく |
| 山（毎週間に合わない） | 84% | 「毎週、その電車には間に合わないんです」と言って、荷物を置いて出て行く |
| 結（鉢を開ける） | 91% | 紙袋の中は葉の垂れた鉢植え。ストーブの脇に置き、日誌に時刻を書く |

ガイドの基準との照合:

- 発端は 3%（基準: 1割以内）。欠落＝乗れない、期限＝明朝、が最初の段落で置かれている
- 承は「頼み込み」の反復が6単位。基準の「三度」より多いが、方向がある。
  電車に乗せろ → 自分で行かせろ → 物だけ運べ、と**頼みが小さくなっていく**（重→軽、外→内）
- 転は 74%（基準: 中央値80%、四分位70〜89%）。類型は露見（駅員が日誌で毎週同じ電車を
  見送っている男だと気づく）。露見は早めという基準（6〜7割）にも近い
- 山は 84%（基準: 95%）でやや早く、そのぶん結が長い。
  結は鉢を開けてストーブの脇に置く2段落で、山から末尾まで 16%（基準: 中央値4.5%、四分位3〜9%）。
  鉢という「渡すはずだったもの」を最後に見せる後日談型の結
- 読者と人物の知識差: 男が何を運ぼうとしているかを読者も駅員も知らないまま承が進み、
  転で駅員だけが「毎週」を知る。読者は駅員と同時に知る型

作家プロファイルではなく、モデル側の癖と読むべき。平均文長 19.5 も中央値 36 より大きく短く、
会話率 0.31 は「頼み込む」というテーマから来る。
