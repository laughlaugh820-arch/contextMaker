# 長さの検証 — 目標 8,000字

```console
$ python3 tools/story.py generate "貸本屋の最後の日、返却されないままの一冊を待つ店主" \
    --plot 露見 --length 8000 --revise 3 --backend cli
```

作家の指定なし（目標は無作為2,000作品の中央値）。展開ガイド §8 の
「8,000〜16,000字は露見（対話）が向く」に従って `--plot 露見` を指定した。

## 稿ごとの推移

| 稿 | 字数 | 達成率 | 平均文長 | 会話率 | 外れた指標 |
| --- | --- | --- | --- | --- | --- |
| 第0稿 | 5,481 | 69% | 21.6 | 0.25 | 3 |
| 第1稿 | 6,032 | 75% | 26.6 | 0.21 | 2 |
| 第2稿 | 6,490 | 81% | 28.0 | 0.21 | 1 |
| **第3稿（採用）** | **8,147** | **102%** | 27.6 | 0.21 | **0** |

## 分かったこと

**初稿の不足率は目標の大きさによらない。** 3,000字の目標では初稿が68〜81%、
8,000字でも69%。つまり `--length` はレバーとして効いていて、大きく指定すれば
そのぶん長く書く。「3,000字が上限」ということではない。

**書き直しの伸び幅は一定ではない。** +551（10%）→ +458（7.6%）→ **+1,657（25.5%）**。
残り1指標が字数だけになった最終回で大きく伸びた。字数と文長と会話率を同時に
指摘していた1・2回目は伸びが鈍い。**指摘が多いほど一つあたりの直しが浅くなる**、
という傾向が見える。長い作品では、字数だけを単独で指摘する回を設けたほうが速いかもしれない。

この結果を見る前、伸び率が10%前後で頭打ちだと判断して「3回でも届かない」と予測したが、
外れた。2回目までの傾向から外挿したのが誤りで、最終回の条件（指摘が字数だけ）が違っていた。

## 節ごと生成（`--sectioned`）との関係

この検証の途中で `--sectioned`（構成表を作ってから節ごとに書く）を実装したが、
8,000字では**使わずに済んだ**。1回の応答で5,500字書けているので、
1回の出力上限にはまだ余裕がある。節ごと生成が要るのは、
初稿が明らかに頭打ちになる長さ（未検証、16,000字以上か）から。
