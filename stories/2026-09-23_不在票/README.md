# 『不在票』— 『返事』の現代語版

読者の依頼「現代っぽい言葉で書いてほしい」を受けて、『返事』（`stories/2026-09-22_返事/`）を書き直したもの。
筋と構造は同じで、文体と小道具を現代に移した。

## 変えたこと

| 項目 | 『返事』 | 『不在票』 |
| --- | --- | --- |
| 語り | 「私」、である調、文語寄り（「局」「鞄」「置いてくるだけのことである」） | 「僕」、だ・である混じりの口語 |
| 路の廃止の理由 | 正式の紙が来た | 本社の業務見直し、採算の合わない特殊郵便の廃止 |
| 配達先 | 河原・沼・山 | 河川敷（市指定文化財の骨）・ダム湖・山の石碑 |
| 返事を書く紙 | 天候を記す紙 | **不在票**の裏。宛先のドラゴンはいつも不在、という仕掛けにした |
| 明かされるもの | 八つの年に届いた紙を油紙に包んで持っている | 財布に二十五年前の不在票。書いたのは前任の坂井さん |

## 読者の指摘への対応

| 指摘 | 対応 |
| --- | --- |
| 結びの雪が突飛で、何の話か分からなかった | 雪を使わない。結びは「古いほうの不在票を財布に戻して、僕はバスを待った」という動作で閉じる |
| 「明日の朝の最後の集配には、別の者が来る」が説明的 | 削除 |
| 「岩の焦げた帯は影に入って見えなかった」が竜の生存と読めた | 焦げた帯の描写ごと削除し、場所は石碑で示す |
| （一対比較で）理由がセットで明かされるのが分かりやすい | 前任者が誰で、いつ知ったかまで一段落で明かす |

**構造は移し替えてもほぼ同じ位置に収まった。** 展開の作法は文体に依存しない。

**文体の指標は3つ基準から外れた**（字数・平均文長・直喩の密度）。これは作品の欠点というより、
層1の目標値の性質を示している。目標値は青空文庫の無作為2,000作品の中央値で、
収録作品の大半は明治〜昭和前期の文章である。現代の口語は文が短く、比喩が少ない。
**層1の文体の目標値は「その時代の文章らしさ」を測っていて、「良い文章」を測っているわけではない。**
現代の文章を評価するなら、目標値を現代の文章から取り直す必要がある（青空文庫には現代の作品がほぼ無い）。

字数の外れは、判定時に既定の目標3,000字を当てたためで、この物語に字数の指定はない。
