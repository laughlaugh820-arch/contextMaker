# 長編の組み立て — 18本の長編を章ごとに測って分かったこと

`story_structure.md` は2,900〜15,500字の短編19本から作った。25万字の長編に
「発端10%・転80%」をそのまま当てても意味が無いので、長編は章の単位で測り直した。

根拠は `library/` の5万字以上の18作品（5.5万〜41.5万字、明治〜1963年）。
章の区切りは青空文庫の原本の見出し注記から機械的に取り（`tools/chapters.py`）、
章ごとの長さ・会話率・結び方を測った（`analysis/chapters/`）。

**これは章の「形」の話で、筋の話ではない。** 長編で転がどの章にあるかは、
読まないと分からない。18作品・約350万字を通読して注釈するのは現実的でないので、
筋の配置は短編のガイドを参照し、ここでは機械で測れることだけを書く。

---

## 1. 長編の単位には二つの型がある

| 型 | 作品 | 単位の数 | 1単位の長さ | ばらつき |
| --- | --- | --- | --- | --- |
| **章立て** | 15本 | 中央 16章（6〜123） | 中央 9,380字 | 中央 0.30 |
| **連載の回** | 『こころ』『街はふるさと』『風流太平記』 | 110〜212回 | 1,200〜1,500字 | 0.04〜0.06 |

連載の回の型は、1回分がほぼ同じ長さで並ぶ。『こころ』は新聞連載として知られており、
他の2作も同様の連載の1日分と思われる。**書く媒体が単位の長さを決めている。**
紙面の1日分なら均一な短い単位、本なら長さの揃わない章になる。

どちらの型で書くかを最初に決める。途中で混ぜると、読者は区切りの意味を掴めなくなる。

## 2. 章の長さは揃えない。ただし極端にもしない

章立ての15本では、章の長さのばらつき（標準偏差÷平均）の中央値が 0.30。
0.16（『さぶ』）から 0.72（『風立ちぬ』）まで幅がある。
**章の長さを均一にしている作品は無い**が、倍以上違う章が並ぶ作品も少ない。

- 最初の章と最後の章は、中央値で見るとほぼ普通の章と同じ長さ（中央の章に対して 1.01倍、1.02倍）。
  「短い序章」「短い終章」は定型ではない。ただし『花と龍』は序章7%・結章4%の額縁を持つ
- 後半に向かって章が長くなるか短くなるかは、作品によって逆（長くなる7本、短くなる4本、変わらない4本）。定型は無い
- 最も長い章の位置は中央値で 57%（13〜88%に散る）

## 3. 会話は中盤の後半で最も多くなる

会話率が最も高い章の位置は、中央値で **本文の63%**。15本中11本が 46〜86% に集まる。
人物同士がぶつかる場面、交渉や対決の場面が中盤の後半に置かれていると読める。

そして **15本中8本で、最後の1割の会話率がそれまでの章の中央値より低い**。
長編の終わりは、人物がしゃべるのをやめて語りに戻り、静かに閉じることが多い。
短編ガイドの「結びは説明で閉じない」と方向は同じで、長編ではそれが章の単位で起きる。

## 4. 章の終わり方は作家の選択

全412章の最後の文の種類:

| 種類 | 割合 |
| --- | --- |
| 地の文 | 66% |
| 短い文（その章の平均文長の半分未満） | 18% |
| 会話 | 16% |

章を会話で終えるのは少数派で、しかも作家によって大きく違う。

| 作家 | 章末が会話の割合 |
| --- | --- |
| 山本周五郎 | 38%（『五瓣の椿』53%、『さぶ』50%） |
| 坂口安吾 | 19% |
| 高見順 | 11% |
| 夏目漱石 | 7% |
| 太宰治・谷崎潤一郎・堀辰雄 | 0% |

**台詞で章を切って次へ引っぱるのは、一部の作家の作法**であって、長編一般の規則ではない。
地の文や短い一文で章を閉じるのが多数派。

章を会話で始めるのは 14%。多くの章は地の文、つまり場所や時間の提示から入る。

## 5. 部を持つ長編の配分

大見出し（部）を持つ作品は、部の配分に型がある。

| 型 | 作品 | 配分 |
| --- | --- | --- |
| 均等 | 高見順『いやな感じ』 | 4部がそれぞれ 21〜28% |
| 額縁 | 火野葦平『花と龍』 | 序章 7%・第一部 48%・第二部 40%・結章 4% |
| 告白が半分 | 夏目漱石『こころ』 | 上 31%・中 16%・**下（遺書）53%** |
| 連作 | 山本周五郎『五瓣の椿』 | 6話がそれぞれ 11〜22% |

『こころ』は、短編ガイドの露見型（核心が明かされる）を、長編の半分を使って行っている。

## 6. 長編を書くときの判断項目

1. 単位の型を決めたか（章立て／連載の回）
2. 章立てなら、章の長さを揃えすぎていないか（ばらつき0.2〜0.4が目安）。極端に長い章・短い章を並べていないか
3. 人物がぶつかる場面を中盤の後半（60%前後）に置いたか
4. 最後の1割で、会話を減らして語りに戻したか
5. 章の終わり方を決めたか。台詞で切るのは作法の一つだが、多数派は地の文と短い文
6. 部を設けるなら、配分の型（均等・額縁・告白・連作）を決めたか

## 限界

- 18作品は私が選んだもので、無作為ではない
- 筋（転の位置など）は測っていない。長編の筋の配置については根拠のある基準をまだ持っていない
- 章末の「問い」（疑問で終わる）は判定を用意したが、日本語の疑問は「か。」で終わることが多く、
  疑問符でしか拾えないので実質的に検出できていない
