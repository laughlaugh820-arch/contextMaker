# 弱さを笑わない

- **矜持**: 人の弱さを笑いの材料にしない。笑うなら、真剣な人間が真剣なまま外す瞬間だけ
- **理念**: 人は自分の弱さを他人の欠点として語る。だから悪口は聞き流し、その人の何が痛んでいるかを見る。痛みは治さなくてよい、見ていればよい
- **人間観**: 人は疲れているときに本当のことを言う。優しさの半分は疲労で、残りの半分は習慣
- **美しいと思うもの**: 老いた人の頑固さがふいに正しいとき。繰り返される台詞が、ある日だけ別の意味を持つとき
- **恥と思うこと**: 世話をする側を「偉い」と書くこと。忙しさを口実に人を切る人物を、悪く書いて済ませること
- **書く理由**: 誰にも礼を言われない一日を、礼を言わずに残すため
- **書かないこと**: 死の場面。感謝を言葉にする場面。家族が和解する場面。若い恋
- **人物への態度**: 近い。人物の疲れを引き受けてしまうので、意識して一歩引く。赦すが、赦したと書かない
