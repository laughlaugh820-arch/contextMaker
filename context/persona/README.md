# 書き手の矜持と理念（ペルソナ）

生成の指示は、コーパスから抽出した数値と作法だけでできている。文の設計は借りられるが、
**書き手が何を譲らず、何を信じて書いているか**はどこにもない。
人間の作家には、自分に課している一線（矜持）と、生き方の軸（理念）がある。
何を美しいと思い、何を恥と思うか。人間をどう見るか。書くことで何をし、何をしないか。
作品の質感の多くはそこから来る。

ここに置くのは、その**考え方を先に決めておく**ための資料。
経歴や職業ではなく、矜持と理念で書く。`tools/story.py` に `--persona <名前>` で渡すと、
「この考え方で書く」としてプロンプトに入る。渡さなければ従来どおり、作法だけで書かせる。
**反映する／しないは生成ごとに選ぶ**もので、どちらが良いかは決めていない。
差は `judge.py pair` の一対比較で測る。

登場人物の設定ではない。書き手が本文に顔を出すこともない。
矜持と理念は、**何を描くか・何を省くか・誰に寄るか・何を美しいと扱うか・どこで終えるか**という選択に出る。

## 何を書くか

| 項目 | 書くこと | 例 |
| --- | --- | --- |
| 矜持 | 自分に課している、譲らない一線 | 見ていないものを見たように書かない |
| 理念 | 生き方の軸。何を正しいとして生きているか | 人は説明されるより、放っておかれるほうが救われる |
| 人間観 | 人間についての、本人が確かめてきた見方 | 人は自分の弱さを他人の欠点として語る |
| 美しいと思うもの | 書き手の目が止まるもの | 直す必要のないものを、それでも直している手 |
| 恥と思うこと | 書き手が自分に許さないこと | 読者を泣かせにいくこと。分かっていないことを分かった顔で書くこと |
| 書く理由 | 何のために書くか | 誰にも数えられなかった時間を数えるため |
| 書かないこと | 理念から導かれる禁じ手 | 救い。悪人。教訓。和解 |
| 人物への態度 | 裁くか、寄るか、赦すか | 誰も裁かない。ただし誰にも味方しない |

## 書き方の約束

- **経歴で書かない。** 職業・年齢・土地は書かない。それらは考え方の出どころであって、考え方そのものではない
- **テーマに依存させない。** どの依頼にも差し込めるよう、特定の筋や人物を書かない
- **名前を書かない。** 実在の作家に寄せない。文体（文の長さ、記号）はコーパスの側で決めるので書かない
- **形容詞で書かない。** 「誠実」「冷徹」は本文で説明に変わる。一線と選択に落とす
- **各項目は1〜3行。** 長いと本文に書き写される
- **書かないことを一つは入れる。** 何でも書く書き手には矜持がない

雛形は [`_template.md`](_template.md)。ファイル名がそのまま `--persona` に渡す名前になる。
名前は職業ではなく、その書き手の理念を一言にしたものにする。

## 使い方

```console
# 一覧（無い名前を渡すと、ある名前を挙げて止まる）
$ python3 tools/story.py compose "冬の停留所で待つ人" --persona ?

# 反映する
$ python3 tools/story.py generate "冬の停留所で待つ人" --persona 見たものしか書かない --backend cli

# 自分で書いたファイルを渡す
$ python3 tools/story.py generate "冬の停留所で待つ人" --persona ~/drafts/私.md --backend cli
```

生成物の `meta.json` に `persona` の名前が残り、使った資料は `stories/<日付>_<題名>/persona.md` に写される
（資料を後で直しても、その生成に何を渡したかが分かる）。

## プロンプトで指示していること

- 項目をすべて使う必要はない。テーマに関わる一線や見方だけが選択に出ればよい
- 書き手は本文に出てこない。「私はこう思う」と語らず、人物に代弁もさせない
- 矜持と理念は、何を描き何を省くか、誰に寄るか、何を美しいと扱うか、どこで終えるかに出す
- 「書かないこと」と「恥と思うこと」は守る。テーマがそれを求めても別の道を探す
- 教訓や主張を書かない。理念は判断に出て、文には出ない

## 測り方

同じテーマ・同じ `--seed`・同じ型で、`--persona` あり／なしを1本ずつ生成し、
`judge.py pair` で順序を入れ替えて2回訊く。作法の観点は列挙しない（既定）。
書き手の考え方は層1〜3の項目にならないので、一対比較の理由の中に何が現れるかで見る。
