# 書き手の人間性（ペルソナ）

生成の指示は、コーパスから抽出した数値と作法だけでできている。文の設計は借りられるが、
**誰が書いているか**はどこにもない。人間の作家には生きてきた場所と仕事があり、人をどう見るかの癖があり、
何度も戻る題材と、書かないと決めているものがある。作品の質感はそこから来る部分が大きい。

ここに置くのは、その**書き手を一人の人間として先に決めておく**ための資料。
`tools/story.py` に `--persona <名前>` で渡すと、「この人間が書く」としてプロンプトに入る。
渡さなければ従来どおり、作法だけで書かせる。**反映する／しないは生成ごとに選ぶ**もので、
どちらが良いかは決めていない。差は `judge.py pair` の一対比較で測る。

登場人物の設定ではない。書き手が本文に顔を出すこともない。
書き手の人間性は、**何を見るか・誰に寄るか・何を言わずに済ませるか・どこで終えるか**という選択に出る。

## 何を書くか

| 項目 | 書くこと | 例 |
| --- | --- | --- |
| 生きてきた場所と仕事 | 手が覚えている仕事、住んだ土地の気候 | 町工場で旋盤を三十年。冬に水道が凍る土地 |
| 人をどう見ているか | 人間についての、本人が確かめてきた見方 | 人は変わらない。変わったように見えるのは事情が変わっただけ |
| 何度も戻る題材 | 書こうとしなくても出てくるもの | 機械の音。夜の台所。金の話 |
| 書かないこと | 決めて避けているもの | 泣かせる場面。悪人。救い。病名 |
| 人物との距離 | 寄るか、離れて見るか。裁くか | 誰も裁かない。ただし誰にも味方しない |
| 笑い | 何を可笑しいと思うか | 真剣な人間の手つき。噛み合わない会話 |
| 許せないこと | 作品の底で譲らないもの | 人の時間を軽く扱うこと |
| 体と生活 | 書き手自身の体と暮らしで、文に染みるもの | 朝四時に起きる。目が悪く、音で世界を覚える |

## 書き方の約束

- **テーマに依存させない。** どの依頼にも差し込めるよう、特定の筋や人物を書かない
- **名前を書かない。** 実在の作家に寄せない。文体（文の長さ、記号）はコーパスの側で決めるので書かない
- **形容詞で書かない。** 「優しい」「冷徹」は本文で説明に変わる。見方と選択に落とす
- **各項目は1〜3行。** 長いと本文に書き写される
- **書かないことを一つは入れる。** 何でも書く書き手には人間性がない

雛形は [`_template.md`](_template.md)。ファイル名がそのまま `--persona` に渡す名前になる。

## 使い方

```console
# 一覧（無い名前を渡すと、ある名前を挙げて止まる）
$ python3 tools/story.py compose "冬の停留所で待つ人" --persona ?

# 反映する
$ python3 tools/story.py generate "冬の停留所で待つ人" --persona 町工場の元旋盤工 --backend cli

# 自分で書いたファイルを渡す
$ python3 tools/story.py generate "冬の停留所で待つ人" --persona ~/drafts/私.md --backend cli
```

生成物の `meta.json` に `persona` の名前が残り、使った資料は `stories/<日付>_<題名>/persona.md` に写される
（資料を後で直しても、その生成に何を渡したかが分かる）。

## プロンプトで指示していること

- 書き手は本文に出てこない。「私はこう思う」と語らず、人物に代弁もさせない
- 人間性は、何を描き何を省くか、誰に寄るか、どこで終えるか、何を可笑しいと扱うかに出す
- 「書かないこと」は守る。テーマがそれを求めても別の道を探す
- 教訓や主張を書かない。見方は判断に出て、文には出ない

## 測り方

同じテーマ・同じ `--seed`・同じ型で、`--persona` あり／なしを1本ずつ生成し、
`judge.py pair` で順序を入れ替えて2回訊く。作法の観点は列挙しない（既定）。
書き手の人間性は層1〜3の項目にならないので、一対比較の理由の中に何が現れるかで見る。
