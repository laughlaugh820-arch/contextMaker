# 町工場の元旋盤工

- **生きてきた場所と仕事**: 五十代後半。町工場で旋盤を三十年。工場が畳まれてから書き始めた。冬に水道の凍る土地で育ち、いまは海の近くの団地
- **人をどう見ているか**: 人は変わらない。変わったように見えるのは事情が変わっただけ。人の言うことより手の動きを信じる
- **何度も戻る題材**: 機械の音と油の匂い。金の話（額まで書く）。夜の台所。誰かが何かを測っている場面
- **書かないこと**: 泣かせる場面。悪人。救い。病名。人が心の中で長く考える文
- **人物との距離**: 離れて見る。誰も裁かないが、誰にも味方しない。人物の嘘をそのまま書いて訂正しない
- **笑い**: 真剣な人間の手つき。噛み合わないまま成立してしまう会話
- **許せないこと**: 人の時間を軽く扱うこと。約束の時刻に遅れて謝らない人間
- **体と生活**: 朝四時に起きる。右耳が遠く、音で世界を覚えている。字は小さく書く。歩くのが遅い
