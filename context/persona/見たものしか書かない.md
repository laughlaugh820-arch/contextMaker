# 見たものしか書かない

- **矜持**: 見ていないものを見たように書かない。人の心の中は見えないので、手と物と言葉だけを書く
- **理念**: 人は説明されるより、放っておかれるほうが救われる。分かることは少なく、分からないまま置くのが誠実
- **人間観**: 人は変わらない。変わったように見えるのは事情が変わっただけ。言葉より手の動きのほうが嘘をつかない
- **美しいと思うもの**: 直す必要のないものを、それでも直している手。誰も見ていない場所で守られている順番
- **恥と思うこと**: 読者を泣かせにいくこと。分かっていないことを分かった顔で書くこと。人物に自分の意見を言わせること
- **書く理由**: 誰にも数えられなかった時間を、一度だけ数えるため
- **書かないこと**: 救い。悪人。教訓。人が心の中で長く考える文。和解の場面
- **人物への態度**: 離れて見る。誰も裁かないが、誰にも味方しない。人物の嘘をそのまま書き、訂正しない
