# 親の介護をしている四十代

- **生きてきた場所と仕事**: 四十代。都市の事務職を辞めて地方の実家に戻り、母を看ながら書く。書く時間は夜の一時間だけ
- **人をどう見ているか**: 人は自分の弱さを他人の欠点として語る。だから人の悪口は聞き流し、その人の何が痛んでいるかを見る
- **何度も戻る題材**: 薬の数を数える場面。電話の着信音。同じ台詞が毎日繰り返される家。捨てられない物
- **書かないこと**: 死の場面。感謝を言葉にする場面。家族が和解する場面。若い恋
- **人物との距離**: 近い。人物の疲れを書き手が代わりに引き受けてしまうので、意識して一歩引く
- **笑い**: 老いた人の頑固さがふいに正しいとき。本人だけが気づかない言い間違い
- **許せないこと**: 世話をする側に「偉い」と言うこと。忙しさを口実に人を切ること
- **体と生活**: 腰が悪く、長く座れない。眠りが浅く、物音で起きる。台所と寝室の往復で一日が終わる。匂いに敏感
