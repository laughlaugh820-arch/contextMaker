# 創作ガイドの検証 — `context/guide/story_craft.md` は妥当か、役に立つか

ガイドの9つの規則を、(1) 統計として正しいか、(2) 実際の創作に効くか、の2点で検証した。

検証に使ったもの:

- **43作品コーパス**の再集計。ガイドが根拠にしている数値に「基準値」を添えた
- **2,000作品の無作為標本**。ミラー全17,436作品から無作為に取り、3千〜30万字・新字新仮名・
  文40以上・平均文長120字以下（韻文・文語を除く）で絞ったもの。ガイドの数値が
  「選び抜いた名作43本」の偏りでないかを見るため。ジャンルの判別はできないので随筆等も混ざる
- **A/B生成**。同じテーマ・同じモデル・同じ system prompt で、ガイドと参照資料を渡した場合と
  渡さない場合を1本ずつ生成し、同じ指標で測って読み比べた（`stories/` 配下）

結論を先に書く。**9規則のうち、統計的に支持されるのは1つ半。3つは根拠が誤りで、
残りは「事実の記述としては正しいが規則に昇格させる根拠がない」。**
一方で A/B では、参照資料を渡したほうが目標の文体に測定可能な差で寄っており、
効いているのは規則の文章ではなく、作家プロファイルの数値と比喩の実例だった。

## 規則1・8: 書き出しと結びの長さ

ガイドの根拠は「1文目が自作の平均文長より短い作品が 27/43」「最終文が短い作品が 26/43」。

これには基準値が要る。文長の分布は右に裾が長い（作品内の 中央値÷平均 は 0.81）ので、
**どの文を選んでも、自作の平均より短い確率はもともと約6割**ある。

| | 43作品 | 2,000作品 | 基準（任意の文） |
| --- | --- | --- | --- |
| 1文目が平均より短い | 63% | 66% | 60〜62% |
| 最終文が平均より短い | 60% | 55% | 60〜62% |

1文目は基準を少し上回る。作品内での百分位で見ると 0.43（特別でなければ 0.50）で、
**短めの傾向はあるが小さい**。「25字前後」という目標値は、1文目の中央値をそのまま
書いただけで、本文の中央値もほぼ同じなので根拠にならない。

最終文は基準を下回る。百分位 0.52。**結びの文は他の文と同じ長さ**で、
「短く切る」という規則はコーパスの事実ではない。

ただし、ガイドが挙げた3つの型（断定型・情景型・関係宣言型）と
「解決を書かず事実を一つ置いて終える」「物や風景に預けて終える」という結びの型は、
統計とは無関係に有用な分類で、実例も正しい。**数値の裏づけを外して、型の提示として残すべき**。

## 規則2: 文長の振れ幅

太宰治 1.19〜1.63、芥川龍之介 0.46〜0.49 という事実は正しい。
2,000作品での振れ幅の中央値は 0.68 なので、両者が両極なのも確か。

ガイドはこれを「語り手の精神状態（動揺／冷静）に対応する」と解釈しているが、
これは検証していない。一人称代名詞の密度との相関は r = −0.02 で、
少なくとも「一人称だから振れる」ではない。作家の癖と読むほうが安全。
**作家の個性を数値で見せる記述としては有用。規則にするなら「意図して選べ」まで**。

## 規則3: 会話は後半に寄せる

| | 後半のほうが会話が多い |
| --- | --- |
| 43作品 | 65%（片側二項検定 p = 0.033） |
| 2,000作品 | 53% |
| うち会話率5%以上 | 59% |

43作品では有意だが、無作為標本では効果がほぼ消える。会話のある作品に絞れば6割弱。
**傾向はあるが弱く、名作の選び方による上振れが混ざっていた**。

『高野聖』の「括弧付きの語り」を分けた指摘は正しく、抽出側の改善として残る。

## 規則4: 比喩は「ようだ」に逃げない

「ようだ型が76%」の内訳を調べると、
`ように思われる`・`ようになった`・`ような顔`・`ように言った` など
**推量・様態・目的の用法が少なくとも29%混ざっている**（抽出の正規表現が区別していない）。
実際の直喩に限っても「ようだ」が主流であることは変わらないが、
2,000作品では 84% とさらに高い。つまり **「ようだ」は日本語の直喩の標準形**であって、
逃げでも癖でもない。

残りの選択肢（ごとし・さながら・あたかも）は文語調で、現代の文体では浮く。
この規則はモデルに古風な形を強いるか、無視されるかのどちらかで、
A/B ではガイドありでも7例すべて「ようだ」型だった（無視された）。

ガイドの本当の主張は「形式ではなく、何に喩えたかで決まる。抽象→具体物へ落とす」で、
**これは統計と無関係に正しく、A/B でも効いていた**（後述）。
形式を禁じる部分を削り、こちらだけ残すべき。

## 規則5: 記号は一方に絞る

| | 両方多用 | 片方 | どちらも無し |
| --- | --- | --- | --- |
| 43作品 | 1 | 12 | 30 |
| 2,000作品 | 13% | 30% | 58% |

千字あたり1以上を「多用」とすると、43作品の7割はどちらも使っていない。
「一方に絞られている」のではなく「どちらも控えめ」が実態。

2,000作品では、両方を多用する割合が **13%**。ダッシュ多用率と三点リーダ多用率が
独立なら 7% のはずなので、**両者は正の相関（r = 0.16）**。
記号を多用する作家は両方使う。ガイドの主張の逆。

芥川のダッシュが「言い直し・割り込み」、堀辰雄の三点リーダが「余韻・中断」という
機能の説明は正しく、有用。**「どちらか一方に決めたほうが締まる」は削るべき**。

## 規則6: 擬音語・擬態語は童話で密度が上がる

上位4作品のうち『蜘蛛の糸』は児童雑誌『赤い鳥』への寄稿で、『走れメロス』は違う。
ジャンルのタグがないので大標本では検証できない。
「声に出して読まれる前提」という説明は後づけ。**仮説として残すなら「未検証」と明記**。

## 規則7: 冒頭で緊張を上げ、中盤で沈める

**集計のバグ**。感嘆符・疑問符のピーク区間を `max()` で取っているため、
記号が1つも無い作品（43作品中13作品）は全区間 0 で、先頭の区間1が「ピーク」になる。
ガイドの「第1区間が13作品と最多」はちょうどこの13作品で、
『羅生門』『鼻』『高瀬舟』『舞姫』など、感嘆符を使わない作品ばかり。

記号ゼロを除くと、43作品のピークは 7〜9 区間に集中（30作品中18）。
2,000作品では各区間 6〜12% でほぼ一様、終盤がわずかに高い程度。
**「冒頭で跳ね上げる」型は存在しない**。「終盤に寄る」も弱い。

「章の長さを揃えない」は、揃っている文章のほうが珍しいので基準がなく、規則として空。

## A/B生成: 資料を渡すと何が変わるか

同じテーマ「古い時計店に持ち込まれた、動かない懐中時計」、同じモデル、同じ system prompt。

| 指標 | ガイド＋資料あり | なし | 参照先（梶井基次郎） |
| --- | --- | --- | --- |
| 字数 | 2,045 | 2,440 | — |
| 平均文長 | 28.5 | 18.3 | 34.3 |
| 文長の振れ幅 | 0.62 | 0.56 | 0.70 |
| 漢字率 | 0.30 | 0.27 | 0.26 |
| ダッシュ/千字 | 1.5 | 0.0 | 3.8 |
| 1文目の百分位 | 0.31 | 0.73 | — |
| 直喩/千字 | 3.4 | 2.0 | — |
| 直喩のうち「ようだ」型 | 7/7 | 5/5 | — |

**効いたもの**

- 文長が参照作家に寄った（18字→28字、梶井34字）。振れ幅も
- 比喩が増え、具体物への喩えになった。「匙に息を吹きかけたあとのような曇り」
  「煮つめた牛乳の表に張るあの膜の色」「干した棗のような指」「籾殻ほどの歯」。
  対照群は「磨いたように澄んでいる」程度で、喩える先が抽象的
- 語り手の気質が参照作家に寄った。病と厭悪、物の冷たさへの執着は『檸檬』の文脈そのもの
- 1文目が短くなった（「冬になると私の指先は死んでいた。」16字、百分位 0.31）

**効かなかったもの**

- 「ようだ」の禁止。両群とも100%「ようだ」型。規則4の形式部分は無視された
- 長さ。目標3,000字に対して 2,045 / 2,440 で、資料を渡したほうが短い
- **筋のオリジナリティ**。両群とも独立に「天輪（テンプ）の軸に髪の毛が一本巻きついて
  止まっていた」という同じ核を書いた。資料は文体を動かすが、モデルが持っている
  題材の定型を動かさない。オリジナリティを求めるなら、文体ではなく筋の側に介入が要る

**読み比べた印象**（1本ずつなので参考程度）

対照群『ひとすじ』は、店じまいする時計屋の一人称で、短文のリズムと昭和の刻印という
仕掛けが整った、破綻のない短編。感傷の落としどころも明確で、読み物としてはこちらが
すんなり入る。

資料あり『鎖のない時計』は、古着に縫い込まれた時計を拾う病身の語り手で、
感覚描写の密度が高く、文体に個性がある。そのぶん「梶井風」に寄りすぎて、
模倣の気配がある。ガイドの「固有名詞と筋は借りない」は守られたが、
気質と文体は借りている。それが狙いなら成功で、独自の文体が欲しいなら行き過ぎ。

## 判定のまとめ

**妥当か**: 記述統計（この作家はこうだった）は正しい。規則への昇格が雑で、
基準値を置かずに「6割がそうだ」を根拠にしたものが4つ（1・3・8、7はバグ）、
逆の結論になるものが1つ（5）ある。

**役に立つか**: 資料を渡すと文体は測定可能に動く。ただし動かしているのは
作家プロファイルの数値と比喩の実例で、ガイド本文の規則ではない。
規則のうちモデルが従ったのは「書き出しを短く」「具体物に喩える」「解決を説明しない結び」で、
これらは統計的根拠が弱いか無いにもかかわらず、**創作の指針としては機能した**。
つまりガイドの価値は「先人がそうしていた割合」ではなく「型の提示と実例」にある。

## 直すべきこと

ガイド:

1. 規則5「一方に絞る」と規則7「冒頭で上げる」を削除。規則8「短く切る」の数値根拠を削除
2. 規則1・8を「型の提示」として書き直し、統計の主張を落とす
3. 規則4から形式の禁止を外し、「抽象→具体物」だけ残す
4. 規則3を「会話のある作品の6割で後半が多い、弱い傾向」に弱める
5. 規則6に「未検証」を付ける
6. 冒頭の注意書きを「名作43本の選択による偏りがあり、無作為標本では多くの傾向が薄まる」に改める

抽出ツール:

7. `tension_curve` のピーク判定で、記号ゼロの作品を除外する
8. `SIMILE_MARKERS["ようだ"]` から `ように思|ように見え|ようになっ|ように言` などの非比喩用法を除く

生成:

9. 筋の定型を避けたいなら、テーマに加えて「使わない題材」をプロンプトで指定できるようにする
   （今回なら「髪の毛」「祖父の遺品」を禁じるだけで別の話になる）

## 対応（検証後に実施したこと）

上の「直すべきこと」9項目のうち、以下を実施した。

**ガイド** — `context/guide/story_craft.md` を全面的に書き直した。
根拠を名作43本の集計から無作為2,000作品の分布（中央値と中央80%帯）に置き換え、
規則5「一方に絞る」と規則7「冒頭で上げる」を削除、規則8の「短く切る」を撤回して
結びの型（事実・動作・風景）の提示に改めた。規則4は「ようだ」の禁止を撤回し、
密度（千字に1が標準）と「抽象→具体物」だけを残した。規則1は「短めの傾向はあるが小さい」
と明記し、型の提示（断定・情景・関係宣言・様式宣言）を主にした。
新たに、段落長（地の文の中央値123字）、記号を一切使わない作品が4割あること、
モデルの題材の定型と作家への寄りすぎの2点を加えた。

**抽出ツール** — `tools/analyze.py` を修正した。
`SIMILE_MARKERS["ようだ"]` から「ように思われる」「ようになった」「ように言った」
「ような顔」などの推量・様態・目的の用法を除いた（「金時のようだ」のような文末の直喩と、
「刻まれたような花」のような動詞＋ような は残す）。43作品での「ようだ」型の割合は
76% → 60% に下がった。緊張曲線に `peak_segment()` を追加し、記号ゼロなら `None` を
返すようにした（`max()` の同順位で先頭区間に倒れるバグの修正）。

**再現性** — `tools/corpus_stats.py` を追加した。ミラーのクローンから無作為標本を取り、
ガイドの分布を `analysis/corpus_distribution.json` に書き出す。この文書の数値は
`--n 2000 --seed 42` で再現できる。

**生成** — `tools/story.py` の「守ること」から「ようだ」の禁止と「記号を一方に絞る」を外し、
長さの下限（目標の90%）、書き出し・結びの型、比喩の密度、「緊張は出来事で作る」に改めた。
`--avoid` で使わせない題材を指定できるようにした。

書き直したガイドと `--avoid 髪の毛 祖父の遺品` で同じテーマを再生成した結果は
`stories/` 配下と、この文書の末尾に追記する。

## 再生成の結果 — 改訂ガイド＋`--avoid` は何を変えたか

同じテーマ・同じモデル・同じ system prompt で3本。指標は修正後の抽出ツールで測り直した
（「ようだ」型の判定が変わったので、初版ガイド版の直喩数は前節の7から5に減っている）。

| 指標 | 初版ガイド | 資料なし | 改訂ガイド＋avoid | 2,000作品の中央値 |
| --- | --- | --- | --- | --- |
| タイトル | 鎖のない時計 | ひとすじ | 針を拾う | |
| 字数 | 2,045 | 2,440 | 2,046 | |
| 平均文長 | 28.5 | 18.3 | 24.7 | 36 |
| 文長の振れ幅 | 0.62 | 0.56 | 0.56 | 0.68 |
| 地の文の段落長 | 125 | 49 | 116 | 123 |
| 会話率 | 0.06 | 0.09 | 0.13 | 0.12 |
| 感嘆疑問/千字 | 0 | 0 | 0 | 0.21 |
| ダッシュ/千字 | 1.5 | 0 | 1.0 | 0.26 |
| 1文目の百分位 | 0.31 | 0.73 | 0.42 | |
| 直喩/千字 | 2.4 | 1.2 | 2.9 | 1.1 |
| うち「ようだ」型 | 5/5 | 3/3 | 6/6 | 69% |

**変わったもの**

- **筋**。前2本が独立に書いた「髪の毛一本で止まった時計」を `--avoid` で外した結果、
  「革職人が針を拾うのに使う磁石が同じ隠しに入っていて、ひげぜんまいが帯磁していた」という
  核になった。物理的に筋が通っていて、しかも「動かす→戻ってくる→また止まる」という
  反復が調べる過程を作っている。3本の中で筋の独自性は明らかに高い
- **模倣の気配が薄れた**。初版ガイド版は病と厭悪という梶井の気質まで借りていたが、
  改訂版は時計屋の一人称で、感覚描写の密度（堀の照り返しが「薄く延ばした錫の板のように」
  天井を撫でる、寄ったひげが「水に濡れた蜘蛛の巣のように」吸い付く、鉄粉が
  「植えたばかりの苗の列のように」並ぶ）は保ったまま、語り手の気質は借りていない
- 会話率が中央値（0.12）に乗り、段落長も中央値（123字）に乗った。分布の地図として
  渡した数値の帯に、実際に入っている
- 結びは型 (c)「視点を風景に預ける」。「堀の照り返しはとうに天井から降りていて、
  硝子戸の外はもう暗かった。」

**変わらなかったもの**

- **長さ**。「3,000字前後、2,700字を下回らない」と明記しても 2,046字。3本とも
  2,000〜2,400字で、この経路（Claude Code CLI）では長さの指示がほぼ効いていない。
  目標の長さで書かせたいなら、プロンプトではなく、短い場合に続きを書かせる
  ループを `story.py` 側に持つ必要がある
- 直喩の形式は「ようだ」100%のまま。ただし改訂ガイドはこれを問題にしていないので、
  もう欠点ではない
- 直喩の密度は 2.9／千字で、参照作家（梶井『檸檬』3.2）に寄っている。
  ガイドの「3で前に出る」の境界にいる。作家を指定しなければ中央値に寄るはず

**判定**。ガイドの数値を分布の地図に改め、`--avoid` で題材の定型を外したことで、
文体は参照先に寄せたまま、筋と語り手の気質は借りない生成物になった。
1本ずつの比較なので効果量は言えないが、方向は狙いどおり。
残る課題は長さの制御で、これはプロンプトでは解決しない。
