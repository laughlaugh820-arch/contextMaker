# 文体の目標値は時代を測っているのか — 時代・ジャンル別の分布

`stories/2026-09-23_不在票/` で、現代語に書き直した作品が層1の文体指標から外れたのを見て、
「目標値は青空文庫の古い文章らしさを測っているのではないか」と考えた。
その仮説を、戦後の長編と片岡義男の作品を足して検証した。**仮説は主要な点で誤りだった。**

## 分かったこと

1. **ジャンルを混ぜた数字では、時代が下っても文は短くならない。** 戦後の中央値 39.2字は明治の 39.5字とほぼ同じで、
   大正・戦前昭和（35字台）より長い。青空文庫の戦後作品には随筆・評論・回想記が多く含まれるためと考えられる
2. **ずれの主因は時代ではなくジャンル。** 小説に絞ると、明治〜戦前の名作も戦後の長編も平均文長は31〜33字で、
   随筆・評論を含む全体（36〜39字）より短い。層1の目標値にしていた無作為2,000作品は、随筆・評論混じりの数字だった
3. **時代の効果が見えるのは片岡義男の 24.7字だけ**で、これは一作家の癖と区別がつかない。
   「現代の小説は文が短い」は、この一群だけでは言えない
4. **直喩の密度はどの時代・どの群でも 1.1前後で安定している。** 『不在票』の 0.44 は時代のせいではなく、
   単に比喩の少ない作品である
5. **会話率はジャンルで大きく変わる**（小説 0.12〜0.31、随筆を含む全体 0.11）。明治の 0.026 は、
   文語体で会話を鉤括弧に入れない書き方が多いため

## 基準に入れた変更

- **文体の目標値の既定を「小説だけの群」に変えた**（`story.py` / `judge.py` の `--baseline fiction`、library/ の小説54本の中央値）
- 現代の小説に寄せたいときは `--baseline modern`（片岡義男の小説11本の中央値）
- 旧来の無作為2,000作品は `--baseline all` で残した

各基準での外れ（字数を除く）:

| 目標値 | 『返事』 | 『不在票』 |
| --- | --- | --- |
| all（随筆・評論を含む） | 平均文長（境界） | 平均文長、直喩 |
| **fiction（既定）** | **会話率** | 平均文長、振れ幅（境界）、直喩 |
| modern | 会話率 | 直喩、会話率 |

小説の基準では『返事』の会話率の低さ（0.021）が初めて引っかかった。
随筆・評論を含む基準では全体の会話率が低めに出るので、見逃していた。

## 限界

- 初出年が奥付に無い作品が 7,628 本（44%）あり、時代別の集計から外れている
- 「小説だけの群」は私が選んだ名作と戦後長編で、無作為ではない。n=54 と小さい
- 現代の群は片岡義男ひとりで、現代の小説一般を代表しない。現代の文体の基準を本気で作るなら、
  国立国語研究所の現代日本語書き言葉均衡コーパスのような、ジャンルと年代の揃った資料が要る
- 青空文庫の目録にはジャンル（NDC 分類）の列があるが、手元のミラーには無い。
  ジャンルで絞れれば、無作為標本から小説だけの分布を大きな n で取り直せる
